## 关键数值与布局核实

- 随包 WASM 对同一样例，未指定状态、`auto`、`none` 与 `battle_stance` 的导入基础耐力均为 **5060**；裸值为 **4600**，“加固板甲”提供 10% 耐力。原失败发生在取消该天赋之后，导入本身没有少算耐力。
- 当前界面通过 `applyCharacterState` 重算职业、种族、天赋和姿态变化，并继续应用手动编辑产生的增幅前修正量。旧 README 的“不覆盖显示值”不再适用，已同步说明。
- 950×650、125% 缩放时，诊断记录为：更早采样 **173**，抽屉打开前 **161**，打开后 **161**。高度差发生在抽屉打开之前；新断言仍要求抽屉打开前后高度完全相等。
- 所有数值、结果数量、标签内容、CSV 和几何条件仍以断言验证，没有删除失败场景或放宽为无条件通过。
